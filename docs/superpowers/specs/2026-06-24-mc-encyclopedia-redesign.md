# 我的世界百科全书 · 重新设计文档

> **一句话定位**：面向5岁儿童的Minecraft像素风格语音图声音典
>
> **版本**：v1.0 · **日期**：2026-06-24

---

## 1. 产品定位

### 1.1 目标用户
- **主要用户**：5岁左右的儿童
- **使用场景**：家长陪同，孩子点击探索
- **核心诉求**：简单直观的交互，像素风格致敬Minecraft

### 1.2 设计理念
- **简单优先**：大按钮、清晰图标、最少文字
- **像素风格**：致敬Minecraft原版，方块感强
- **即时反馈**：每次操作都有音效和动画响应

## 5. 视觉设计

### 5.1 像素风格规范
- **字体**：Press Start 2P（像素字体）
- **边框**：方块感，无圆角
- **配色**：8-bit风格
- **图标**：像素化处理

### 5.2 配色方案

## 6. 交互设计

### 6.1 页面流程
```
[首页] → 点击"开始探索" → [分类页] → 点击分类 → [详情页]
```

### 6.2 导航方式
- 每页都有清晰的返回按钮（像素风格箭头）
- 详情页有"上一个/下一个"按钮
- 分类内循环浏览

### 6.3 音频交互
- 点击播放按钮开始朗读
- 再次点击暂停
- 播放中点击插画播放音效
- 朗读优先级高于音效

## 7. 组件设计

### 7.1 PixelButton
- 像素风格边框
- 点击时有8-bit音效
- 悬停/按下状态变化

### 7.2 PixelCard
- 像素边框
- 点击时有弹跳动画
- 显示图标和文字

### 7.3 AudioPlayer
- 大按钮，易于点击
- 播放状态显示
- 加载/错误状态处理

### 7.4 PixelImage
- 显示PNG图片
- 加载失败显示占位图
- 点击时有像素动画
