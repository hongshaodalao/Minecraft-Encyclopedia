# 多模态处理规则

## 模型选择

当任务涉及以下多模态场景时，使用 `mimo-v2.5` 模型：

### 触发条件

| 场景 | 示例 |
|------|------|
| **图片分析** | 查看 WebP/PNG/JPG 图片内容、识别图片中的元素 |
| **图片描述** | 为 `public/images/` 下的游戏素材生成文字描述 |
| **视觉审查** | 检查 UI 截图、验证图片质量、对比设计稿 |
| **视频处理** | 分析视频帧、提取关键画面、生成视频摘要 |
| **图文结合** | 根据图片内容生成文案、校验图文匹配度 |

### 调用方式

```typescript
// Agent 调用时指定模型
agent('分析图片内容并生成描述', { model: 'mimo-v2.5' })
```

### 本项目典型用例

1. **词条图片审查**
   - 检查 `public/images/{category}/{id}.webp` 是否符合手绘风格
   - 验证图片内容与词条名称是否匹配

2. **批量图片描述生成**
   - 为无障碍访问生成 alt 文本
   - 为语音朗读提供图片上下文

3. **UI 截图验证**
   - 审查页面布局和视觉效果
   - 对比设计规范（圆角、配色、间距）

## 注意事项

- 纯文本任务（代码编写、JSON 处理、类型检查）**不使用** mimo-v2.5
- 图片路径验证、文件存在性检查等**不需要**视觉理解的任务使用默认模型
- 当不确定是否需要多模态时，优先用默认模型；仅在确实需要"看"内容时切换
